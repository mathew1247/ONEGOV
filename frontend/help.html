How ONEGOV Works

Government departments in India maintain independent portals, registries, and databases. ONEGOV acts as a secure, decentralized middleware integration layer that standardizes data formats (JSON, SOAP/XML, Flat SQL) without replacing existing departmental infrastructure.

1. Single Demographic Intake: Enter verified basic demographic data once.
2. Explicit Digital Consent: Authorize each target department system individually.
3. Automated Multi-Protocol Adapters: Real-time cross-verification across education, revenue, and employment registries.
4. End-to-End Traceability: Track lifecycle progress with instant cryptographic sanction orders.

Frequently Asked Questions

How does ONEGOV work?

ONEGOV orchestrates API data exchange between citizen frontend requests and participating government databases. Instead of requiring manual document uploads, the platform uses protocol adapters to fetch and verify credentials directly.

How is my personal information shared?

Data is exchanged only when you explicitly grant consent for a specific service. Data tokens are fetched on-demand, validated against the OneGov Common Data Schema (OCDS), and are not sold or retained for advertising.

What is digital consent?

Under the Digital Personal Data Protection (DPDP) Act 2023, digital consent is your sovereign permission granting access to specific parameters (such as degree completion or income slab) for a declared purpose. You can revoke this anytime.

How can I track my application?

Every submitted application generates a unique tracking reference (e.g. ONE-2026-00124). You can visit the My Applications page or paste your ID into the tracking portal to see live telemetry across all connected systems.

What happens if a department system is unavailable?

The ONEGOV middleware incorporates automated Circuit Breakers (Closed/Open/Half-Open) and Dead-Letter Queues (DLQ). If a department server times out, the system automatically retries with exponential backoff without losing your application progress.
